Chapter 3 of 4

The Three Primitives in Action

Deep dive into the 3 atomic operations: closest, querySelectorAll, and mapValues.

Story Index

1 Instruction 1: closest("tr")

Ascend to Boundary

The Problem: When a user clicks a button, the click might land on the button, an icon tag inside the button (<i class="bi bi-eye"></i>), or a text span. Imperative code like e.target.parentElement.parentElement breaks immediately.

The Primitive Solution: closest(selector) inspects the target and walks up the DOM ancestor chain until it finds the nearest matching selector: 

{
  "sourcePath": { "fileName": "root" },
  "func": "closest",
  "arguments": { "selector": "tr" }
}
Immune to nesting: Whether the click landed on an icon 3 levels deep or the button itself, closest("tr") always locks reliably onto the containing row.

2 Instruction 2: querySelectorAll

Filter Payload

The Problem: A table row contains not just data, but layout noise: action buttons, checkboxes, and serial numbers. If you simply take all children, your data indexes become corrupt.

The Primitive Solution: Query the row using CSS negation selectors to gather only the cells holding business data: 

// Exclude the last cell (the Action/Options button column):
{
  "sourcePath": { "fileName": "previous" },
  "func": "querySelectorAll",
  "arguments": { "selector": "td:not(:last-child)" }
}

// Or if a serial number column exists, exclude first and last:
"selector": "td:not(:first-child):not(:last-child)"
Self-filtering: The selector discards button cells before mapping even begins. The output of this step is a clean array of pure data cells.

3 Instruction 3: mapValues

Bridge to Schema

The Problem: The browser only gives you DOM nodes. Your application needs a typed, structured JavaScript object with semantic property names.

The Primitive Solution: mapValues takes the array of cells, pairs each cell index with clientData.columns, reads the cell content, and produces a clean object: 

// Instruction:
{
  "sourcePath": { "fileName": "previous" },
  "func": "mapValues",
  "arguments": { "read": "text" }
}

// Client Data Schema:
const clientData = {
  columns: ["itemName", "category", "rate"]
};

// Output:
{
  "itemName": "High Tensile Bolt",
  "category": "Fasteners",
  "rate": "1200.00"
}
Smart Value Reading: If a cell contains an <input> or <select> instead of plain text, changing read: "value" automatically reads .value or .checked without writing custom form extraction code.
