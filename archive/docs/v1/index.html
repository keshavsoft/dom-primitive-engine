DOM Primitive Engine

Browser-native, declarative, instruction-driven DOM extraction with zero external dependencies.

Repository

The Problem: Brittle Traversal

When users click inside dynamic tables or forms, developers frequently write imperative, tightly-coupled queries: 

// Brittle & fragile:
const row = btn.closest("tr");
const cells = row.querySelectorAll("td");
const item = {
  name: cells[1].innerText, // Breaks if serial # is added!
  category: cells[2].innerText
};

Adding a checkbox column or moving an action button silently corrupts the extracted data.

The Solution: Declarative Pipelines

The event listener receives the click, while an instructions.json pipeline defines the extraction journey: 

// Clean & decoupled:
button.addEventListener("click", (e) => {
  const rowData = extractRow(e.currentTarget);
  console.log("Extracted:", rowData);
});

Decouples UI rendering from data extraction. Extraction rules can be shared, versioned, or loaded dynamically.

The 3-Stage Pipeline Lifecycle

Each step receives an input, executes an atomic DOM primitive, and forwards the result to the next step:

Clicked Element (root)
→
1. closest("tr")
→
2. querySelectorAll("td")
→
3. mapValues(columns)
→
Clean JS Object

The Instruction Contract (v13)

Below is the exact instructions.json executed by the v13 engine: 

[
  {
    "narration": "Find the table row containing clicked element",
    "sourcePath": { "fileName": "root" },
    "func": "closest",
    "arguments": { "selector": "tr" }
  },
  {
    "narration": "Collect data cells from the row",
    "sourcePath": { "fileName": "previous" },
    "func": "querySelectorAll",
    "arguments": { "selector": "td:not(:last-child)" }
  },
  {
    "narration": "Map cell values to client columns",
    "sourcePath": { "fileName": "previous" },
    "func": "mapValues",
    "arguments": { "read": "text" }
  }
]
Field Purpose
narration Human-readable description for debugging and logging.
sourcePath.fileName Where the input originates:
  • "root": Starting element (event target)
  • "previous": Output of preceding step
  • "clientData": Shared client data
func The primitive function to run (e.g. closest, querySelectorAll, mapValues).
arguments Arguments passed to the operation (e.g. CSS selector, read mode).

Standard Primitives in v13

Primitive Category Description Signature
closest find Finds nearest ancestor-or-self matching the CSS selector. (input, { selector })
querySelectorAll find Queries child elements matching selector; returns JS Array. (input, { selector })
readText read Reads .textContent with optional whitespace trimming. (input, { trim: true })
readValue read Smart-reads form controls: checkbox checked state, select values, inputs. (input)
mapValues mapping Maps an array of elements by index to clientData.columns. (elements, { columns, read }, clientData)
mapNamedValues mapping Extracts controls with name attributes into { [name]: value }. (controls)
