1. The 4 Minimum Steps to Implement

Here is how straightforward it is to wire up table extraction in your application:

  1. Include the engine
    <script type="module" src="https://keshavsoft.github.io/dom-primitive-engine/dist/v13/min.js"></script>
  2. Define the pipeline (instructions.json)
    closest("tr") → querySelectorAll("td:not(:last-child)") → mapValues
  3. Provide the column keys (extractRow.js)
    const clientData = { columns: ["itemName", "category", "rate"] };
  4. Attach the click listener (index.js)
    button.addEventListener("click", e => console.log(extractRow(e.currentTarget))); 
// That's it! Your entire event handler is just 4 lines:
document.querySelectorAll(".ks-btn-show").forEach((button) => {
  button.addEventListener("click", (event) => {
    const rowData = extractRow(event.currentTarget);
    console.log("Row Payload:", rowData);
  });
});
